# Instrucciones para Claude

Leer y respetar [AGENTS.md](AGENTS.md) y [README.md](README.md).

Para acompañar a un compañero desde cero, empezar por [el tutorial paso a paso](01%20Docx/PASO_A_PASO_PARA_COMPANEROS.md), incluidos tiempo real, actualización y límites de GitHub.

Para publicar un dashboard o elegir alojamiento, seguir [la guía multiplataforma](01%20Docx/PUBLICAR_DASHBOARDS_MULTIPLATAFORMA.md). Preguntar el destino solo si todavía no está decidido. Esta web ya usa GitHub Pages; no migrarla a otro proveedor sin petición del usuario. No usar OpenAI Sites por defecto.

Preservar las cuatro carpetas del proyecto, el cifrado y los archivos existentes. No guardar secretos ni publicar el repositorio completo como carpeta web.
